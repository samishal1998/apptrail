## Your next stop is one command away.

Install the latest release on Linux or macOS. The installer verifies the release checksum and installs into your user's local bin directory.

```sh
curl -fsSL https://samishal1998.github.io/apptrail/install.sh | sh
```

Then install and start it as a background service:

```sh
~/.local/bin/apptrail service install
```

Open port **8080**, use the setup token from the data directory shown by the CLI, and create your owner account. Apptrail uses systemd on Linux and launchd on macOS. Windows Services and ready-to-pull container images are covered in the installation guide.

Prefer Docker? Download the Compose file and start the prebuilt image:

```sh
curl -fsSL https://samishal1998.github.io/apptrail/compose.yaml -o compose.yaml
docker compose up -d
```

# Apptrail working pack

This working pack contains the product/technical design and all assets that can be generated without altering the approved brand mark or extracting pixels from the approved UI concept.

## Included now

- `docs/APPTRAIL_PRD.md` — full product requirements document
- `docs/BRAND_GUIDE.md` — visual direction and usage rules
- `themes/` — dark/light design tokens and CSS
- `iconography/` — original supporting SVG icon set
- `schemas/` — discovery manifest JSON Schema
- `examples/` — provider, label, and manifest examples

## Final-image assets intentionally pending

- canonical Apptrail logo mark/lockups
- clean mountain/sunset backgrounds
- rendered theme mockups using the locked canonical mark

These are not being reconstructed or cropped from the screenshot because the requirement is to preserve the exact approved mark and visual direction while regenerating clean standalone assets.

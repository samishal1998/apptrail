# Apptrail Brand & UI Direction

## Locked direction

Apptrail uses the dark Wayboard-inspired visual direction selected in the approved concept while retaining the Apptrail name and Apptrail mark.

### Core visual traits

- deep navy/charcoal surfaces;
- sunset orange primary accent;
- atmospheric mountain landscape;
- thin translucent borders;
- restrained glass effects;
- large rounded cards;
- white/off-white primary text;
- muted cool-gray secondary text;
- sparse line iconography;
- green status only for healthy/online state;
- amber star for favorite state.

## Theme names

- `apptrail-dark` — primary/default theme.
- `apptrail-light` — companion light theme using the same component geometry.

## Brand mark rule

The canonical mark is immutable once exported. Never redraw it per asset. Every logo lockup, favicon, app icon, preview, and theme must reuse the same master source.

## Typography

Recommended UI stack:

```css
font-family: Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont,
             "Segoe UI", sans-serif;
```

A product implementation may substitute another modern grotesk, but should not mix multiple display faces in the core UI.

## Radius scale

- small controls: 10px
- pills: 999px
- cards: 16px
- large panels: 20px

## Spacing

Use a 4px base with primary steps of 8, 12, 16, 24, 32, and 48px.

## Logo clear space

Maintain clear space around the mark equal to at least 25% of the mark width.

## Background usage

The mountain/sunset scene is atmospheric support, not information. UI text must remain readable without depending on the image. Apply a dark overlay or gradient behind dense content regions.
